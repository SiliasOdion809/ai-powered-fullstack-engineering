# Assignment 1 — HTML Fundamentals

This project is the first practice assignment completed as part of my **AI-Powered Fullstack Engineering** program at **AltSchool Africa, School of Engineering**.

The assignment focuses on building accessible and semantically structured web pages using **HTML only**, without CSS or JavaScript.

## 📌 Project Overview

The project consists of two HTML pages:

- **Personal Profile Page** — A personal profile containing my background, motivation for joining the program, goals for the School of Engineering program, and an accessible FAQ accordion.
- **Application Form Page** — An HTML implementation of the AltSchool account creation form using accessible and semantic form elements.

## 🎯 Learning Objectives

This assignment was designed to help me practice:

- Writing well-structured HTML5 documents
- Using semantic HTML elements
- Creating accessible navigation
- Working with headings and document structure
- Creating accessible forms
- Using labels and appropriate input types
- Working with links and fragment identifiers
- Creating native HTML interactive components
- Understanding basic web accessibility principles
- Organizing a multi-page HTML project

## 🛠️ Technologies Used

- HTML5
- Semantic HTML
- Accessible HTML forms

> **Note:** This assignment was intentionally completed without CSS or JavaScript as required by the task.
